# Roadmap para convertirte en Desarrollador Full Stack (desde cero)

**Dedicación estimada:** 3-4 horas diarias
**Duración estimada total:** 8-10 meses
**Meta final:** Conseguir tu primer trabajo como desarrollador full stack junior

---

## Cómo usar este roadmap

- No te saltes las bases. El 80% de los que abandonan programación lo hacen por querer ir muy rápido y no entender los fundamentos.
- Programa todos los días, aunque sea poco. La consistencia importa más que la intensidad.
- Construye proyectos reales desde el mes 1, no solo veas tutoriales.
- Sube todo tu código a GitHub desde el primer día. Será tu portafolio.

---

## FASE 0: Fundamentos de la computación (1 semana)

- Qué es un lenguaje de programación, compilación vs interpretación
- Terminal / línea de comandos básica (navegación, crear archivos/carpetas)
- Qué es Git y por qué se usa (control de versiones)
- Crear cuenta en GitHub

**Recursos:**
- freeCodeCamp - "Command Line for Beginners"
- Git y GitHub para principiantes (canal de midudev o freeCodeCamp en YouTube)

---

## FASE 1: Fundamentos web - HTML, CSS y lógica de programación (6-8 semanas)

### HTML y CSS (2 semanas)
- Estructura de una página web, etiquetas semánticas
- CSS: selectores, box model, Flexbox, Grid
- Diseño responsive (media queries)

**Proyecto:** Landing page estática (tu portafolio inicial, sin funcionalidad)

### Lógica de programación con JavaScript (4-6 semanas)
- Variables, tipos de datos, operadores
- Condicionales, bucles
- Funciones, scope
- Arrays y objetos, métodos de arrays (map, filter, reduce)
- Manipulación del DOM
- Eventos
- Fetch API básico (consumir una API pública)

**Proyectos:**
- Calculadora
- Lista de tareas (To-Do list) con JavaScript puro
- Juego simple (Piedra, papel o tijera / Buscaminas)

**Recursos:**
- freeCodeCamp - Responsive Web Design y JavaScript Algorithms
- "JavaScript.info" (referencia gratuita muy completa)
- The Odin Project (ruta completa gratuita, muy recomendada)

---

## FASE 2: JavaScript moderno y Frontend con framework (6-8 semanas)

### JavaScript avanzado (2 semanas)
- ES6+: arrow functions, destructuring, spread/rest, módulos
- Promesas y async/await
- Programación asíncrona en profundidad

### React (4-6 semanas)
- Componentes, props, estado (useState)
- Hooks (useEffect, useContext, custom hooks)
- Renderizado condicional y listas
- Formularios controlados
- React Router (navegación)
- Consumo de APIs REST desde React
- Manejo de estado global (Context API, luego opcional: Zustand o Redux)

**Proyectos:**
- Clon de una app conocida (ej. clima, clima con geolocalización)
- App de recetas o películas consumiendo una API pública
- Dashboard con datos y gráficas

**Recursos:**
- Documentación oficial de React (react.dev)
- Curso de React de midudev / Fazt / freeCodeCamp
- Frontend Mentor (retos de diseño reales para practicar)

---

## FASE 3: Backend (6-8 semanas)

### Node.js y Express (3-4 semanas)
- Qué es un servidor, cliente-servidor, HTTP
- Node.js básico
- Express: rutas, middlewares
- API REST: CRUD completo
- Autenticación con JWT
- Variables de entorno, manejo de errores

### Bases de datos (3-4 semanas)
- SQL: qué es, modelado relacional, consultas básicas (SELECT, JOIN, WHERE)
- PostgreSQL o MySQL en la práctica
- ORM: Prisma o Sequelize
- NoSQL: MongoDB básico (para entender la diferencia)

**Proyectos:**
- API REST completa con autenticación (registro/login) y base de datos
- Backend para tu app de tareas o recetas anterior, conectando todo

**Recursos:**
- Curso Node.js + Express de freeCodeCamp
- "SQL for beginners" (freeCodeCamp)
- Documentación de Prisma

---

## FASE 4: Full Stack real + Herramientas profesionales (4-6 semanas)

- Conectar tu frontend en React con tu backend en Express (proyecto completo end-to-end)
- Git avanzado: ramas, pull requests, resolución de conflictos
- Deploy: Vercel/Netlify (frontend), Railway/Render (backend), o un VPS básico
- Testing básico (Jest para backend, React Testing Library para frontend)
- Docker (conceptos básicos, para que no te suene raro en entrevistas)
- TypeScript (recomendado antes de buscar trabajo, muy pedido hoy en día)

**Proyecto grande final (full stack, deployado y funcional):**
Ejemplos: red social simple, e-commerce básico, app de gestión de tareas con equipos, clon de Twitter/Instagram simplificado. Debe tener: autenticación, base de datos, CRUD completo, frontend en React, y estar publicado en internet con una URL real.

---

## FASE 5: Preparación para conseguir trabajo (3-4 semanas, en paralelo a la Fase 4)

- Arma tu portafolio (sitio propio mostrando 3-4 proyectos)
- Optimiza tu perfil de LinkedIn y GitHub
- Prepara tu CV enfocado en tech
- Practica algoritmos y estructuras de datos básicas (para entrevistas técnicas)
  - LeetCode (nivel fácil), o mejor aún: NeetCode 150
- Practica preguntas de entrevista técnica y de comportamiento
- Empieza a aplicar a posiciones junior/trainee mientras terminas tu proyecto final

**Recursos:**
- roadmap.sh/full-stack (referencia visual del camino completo)
- NeetCode.io (algoritmos explicados en video)

---

## Stack final que dominarás

**Frontend:** HTML, CSS, JavaScript, React, TypeScript
**Backend:** Node.js, Express
**Bases de datos:** PostgreSQL/MySQL, MongoDB (básico)
**Herramientas:** Git/GitHub, Docker (básico), Vercel/Railway (deploy), Postman

---

## Consejos finales

1. No esperes a "sentirte listo" para aplicar a trabajos. Aplica cuando tengas 2-3 proyectos sólidos.
2. Participa en comunidades (Discord de programación, foros locales) — te ayuda a no sentirte solo y a resolver dudas más rápido.
3. Documenta tu proceso (LinkedIn, Twitter/X, o un blog). Muchos reclutadores valoran ver el progreso.
4. Los primeros 2-3 meses son los más difíciles. Después de eso, todo empieza a encajar más rápido.
